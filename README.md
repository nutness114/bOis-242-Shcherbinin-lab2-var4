# Лабораторная работа 2 — «Лови шарик»

Проект реализован на JavaFX в архитектуре MVVM.

## Что уже настроено

- `src` подключён как папка с исходниками
- `resources` подключён как папка ресурсов
- создан модуль `Labb 2.iml`
- добавлена run-конфигурация `GameApplication`

## Как запускать

1. Открой папку проекта `D:\Student\Щербинин\Кроссплатформы\Лабы\Labb 2` в той же IDE, где запускалась первая лабораторная.
2. Дождись, пока IDE подхватит `.idea` и `Labb 2.iml`.
3. В списке конфигураций выбери `GameApplication`.
4. Нажми `Run`.

Главный класс для запуска: `catchball.GameApplication`

## Архитектура

- `GameModel` хранит состояние игры, движение шарика, счёт, серию попаданий и бонусные очки
- `GameController` связывает модель и FXML, обрабатывает события мыши и запускает новую игру
- `GameView.fxml` описывает интерфейс и игровое поле

## Индивидуальный вариант 4

Если игрок попадает по шарику несколько раз подряд без промахов, начисляются дополнительные очки:

- 1-3 попадания подряд: 1 очко
- 4-6 попаданий подряд: 2 очка
- 7-9 попаданий подряд: 3 очка
- дальше бонус продолжает расти каждые 3 точных попадания подряд

Промах по полю сбрасывает серию.
