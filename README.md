# Лабораторная работа 2 — «Лови шарик»

Учебный проект на JavaFX по архитектуре MVVM.

## Описание проекта

Приложение представляет собой мини-игру, где пользователь должен попадать по движущемуся шарику.  
За попадания начисляются очки, а промахи сбрасывают серию. Интерфейс построен на JavaFX + FXML, логика игры вынесена в модель, а обработка событий находится в контроллере.

## Что реализовано

- запуск JavaFX-приложения через `catchball.GameApplication`
- интерфейс игры в `FXML`
- движение шарика внутри игрового поля
- обработка попаданий и промахов мышью
- кнопка `Новая игра`
- пауза по двойному клику по шарику
- отображение счёта, серии попаданий, статуса игры и скорости шарика

## Индивидуальный вариант 4

По заданию реализована бонусная система за серию точных попаданий без промахов:

- за 1-3 попадания подряд начисляется `1` очко
- за 4-6 попаданий подряд начисляется `2` очка
- за 7-9 попаданий подряд начисляется `3` очка
- далее бонус продолжает увеличиваться на `1` за каждые следующие 3 точных попадания подряд
- любой промах по игровому полю сбрасывает серию

## Какие индивидуальные правки я сделал в сам проект

Кроме базовой реализации игры, в проект добавлены и оформлены такие доработки:

- отдельная модель `GameModel`, где сосредоточена вся логика движения, счёта и бонусной серии
- реакция шарика на курсор: при приближении мыши шарик старается убегать, поэтому игра не выглядит статичной
- ограничение движения по границам игрового поля с отскоками
- случайное изменение траектории во время движения, чтобы поведение шарика было менее предсказуемым
- пауза по двойному клику по самому шарику
- вывод текущей скорости шарика в интерфейсе
- отдельный статус игры: активна или пауза
- кнопка быстрого запуска новой партии без перезапуска программы
- добавлен `pom.xml`, чтобы проект открывался в GIGA IDE и воспринимался как Maven-проект

## Как запустить проект в GIGA IDE

1. Откройте проект `D:\Student\Щербинин\Кроссплатформы\Лабы\Labb 2` в `GIGA IDE`.
2. Дождитесь, пока IDE проиндексирует проект и подхватит `pom.xml`.
3. Если справа появится окно `Maven`, нажмите `Reload`, чтобы IDE перечитала зависимости и структуру проекта.
4. Откройте [GameApplication.java](/D:/Student/Щербинин/Кроссплатформы/Лабы/Labb%202/src/catchball/GameApplication.java).
5. Нажмите зелёный треугольник рядом с методом `main`.
6. Выберите `Run 'GameApplication.main()'`.

Если конфигурация уже подхватилась из `.idea/workspace.xml`, можно просто выбрать готовый запуск `GameApplication` в правом верхнем углу IDE и нажать `Run`.
